/// Hướng dẫn sử dụng api

1. "aff_product_code" : Mã sản phẩm trên sàn aff
2. "name" : Tên sản phẩm
3. "slug" : Đường dẫn sản phẩm trên website
4. "status" : Trạng thái (0: Lưu nháp, 1: Xuất bản)
5. "type" : Loại sản phẩm (0: Sản phẩm thông thường, 1: Sản phẩm affiliate)
6. "cate_id" : ID danh mục sản phẩm trên website
7. "price" : Giá bán
8. "base_price" : Giá trước giảm
9. "revenue_price" : Hoa hồng (người mua hàng có thể nhận) / sản phẩm
10. "body" : Chi tiết sản phẩm
11. "intro" : Mô tả ngắn
12. "short_des" : Giới thiệu
13. "origin_id" : ID của sàn aff
14. "origin" : Tên sàn
15. "origin_link" : Link gốc sản phẩm
16. "aff_link" : Link affiliate
17. "short_link" : Link rút gọn
